# Evidence and scope

This repository curates existing work for a particular review path. It is a documentation portfolio, not a separate software implementation or an employer deliverable.

| Evidence class | How to interpret it |
|---|---|
| Observed / captured | The cited case records a real page or bounded read-only observation. |
| Source / architecture | Public implementation or documentation supports a design discussion; live acceptance is separate. |
| Historical | My experience and surviving partial records; unavailable historical behavior is not reconstructed as current proof. |
| Preview | Fictional or empty data and mocked responses remain labeled. |
| Proposed | Tabletop procedures, review frameworks, and roadmap items are not completed operating results. |
